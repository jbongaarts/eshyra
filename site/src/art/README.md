The art assets in this directory were generated for the Eshyra landing page
using Vercel/v0's GenerateImage tooling and exported as part of the site
redesign integrated in PR #329.

These are decorative site assets, not rules-pack content and not part of the
D&D SRD-derived downloadable data.

`midnight-library.webp` was generated for the editorial redesign with ChatGPT's
built-in image generation tool, then encoded as WebP for delivery (1536 × 1024).
It is original decorative artwork, not SRD content. The generation prompt was:

> A finished landscape illustration for Eshyra: a richly painted 1980s fantasy
> roleplaying sourcebook illustration crossed with early home computing. An
> elderly wizard in a deep blue robe uses a beige CRT computer with an amber
> screen at a wooden desk in a candlelit gothic library. Books, maps, a carved
> stone dragon, and a midnight-blue fantasy city beyond the arches. Oil and
> gouache texture, deep ink-blue shadows, restrained amber-gold light. Wizard
> and computer toward the right, distant architecture on the left. Full-bleed
> artwork only; no typography, borders, logos, or readable text.
